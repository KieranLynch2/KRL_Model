A model to simulate the evolution of second phase particles (SPPs) in Zircaloys based on the Kampmann-Wagner numerical model, along with sub-models to predict SPP amorphization and dissolution under irradiation. 

Version 1 relates to the first version of this model, published in 2023. Full details and information about this version of the model are found in reference 1.

Version 2 is an updated version of the model, with some minor changes to the simulation of quenching in Zircaloy-4 and significant changes to the dissolution of Zr(Fe,Cr)2 SPPs during irradiation. Full details and information about this version of the model can be found in reference 2. This version is recommended as it offers improvements over version 1.
